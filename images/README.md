# Imágenes

Sustituir las imágenes sin tocar los componentes.

Carpetas:
- `brand/`
- `home/`
- `servicio-tecnico/`
- `patinetes/`
- `fibra-movil/`
- `empresas/`
- `tienda/`

Recomendación:
- WebP o AVIF
- fondo limpio cuando sea posible
- evitar texto incrustado en la fotografía
- mantener nombres descriptivos y estables
